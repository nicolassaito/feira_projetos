Sistema de Monitoramento Termo-Higrométrico Dinâmico

Análise contínua em tempo real de microclimas para estufas com carimbo temporal via RTC, exibição gráfica em tela OLED e diagnóstico visual com sinalização em estado sólido.

01. Fundamentação

Proposta Técnica do Projeto

Desenvolvido como projeto integrador no curso de Engenharia Elétrica, focado em instrumentação eletrônica, protocolos de comunicação e controle visual.

Controle de Temperatura

Faixa operacional ideal mantida entre 18°C e 28°C para mitigação de estresse térmico em culturas sensíveis.

Umidade Relativa (%RH)

Amostragem dinâmica mantida entre 50% e 75% de umidade relativa, prevenindo proliferação de fungos ou desidratação.

Selo Temporal RTC

Sincronismo exato de data e hora independente de quedas de energia através de cristal TCXO compensado por temperatura.

Objetivos de Engenharia

< 2s Taxa de Atualização
I²C Barramento Único (OLED+RTC)
3 Níveis Sinalização de LED
5V CC Baixo Consumo

02. Topologia do Sistema

Funcionamento do Circuito & Classificação

CONTROLADOR

Microcontrolador ATmega328P

Processa os dados seriais do sensor DHT, requisita informações de hora via barramento I²C e gerencia as saídas lógicas.

SENSOR

Sensor DHT11 / DHT22

Converte variações físicas de temperatura e umidade relativa em um sinal digital codificado de 40 bits via pino dedicado.

SENSOR / RTC

Módulo RTC DS3231

Relógio em Tempo Real de alta precisão com cristal interno compesado por temperatura. Fornece o carimbo de data e hora exatos.

ATUADOR / EXIBIÇÃO

Display OLED 0.96" SSD1306

Interface Homem-Máquina visual. Exibe em matriz de 128x64 pixels a temperatura, umidade, data, hora e ícones de status.

ATUADOR SINALIZADOR

LEDs Indicadores de Faixa

Sinalização luminosa de estado sólido (Verde: Ideal, Amarelo: Alerta/Atenção, Vermelho: Crítico/Fora de faixa).

Fluxograma de Lógica de Controle

Clique em qualquer etapa para destacar o comportamento do sistema:

1
POWER-ON & INICIALIZAÇÃO Inicializa barramento I²C (0x3C OLED, 0x68 RTC) e pino DHT
2
AQUISIÇÃO DE DADOS Lê timestamp do DS3231 e quadro de 40 bits do sensor DHT
3
COMPARAÇÃO DE LIMITES Avalia se (18°C ≤ Temp ≤ 28°C) e (50% ≤ Hum ≤ 75%)
4
SINALIZAÇÃO E DISPLAY Atualiza OLED com telemetria e comuta o nível lógico dos LEDs
5
DELAY CICLICO (2000ms) Aguardar ciclo mínimo de estabilização do sensor térmico

04. Especificação de Hardware

Componentes Técnicos e Justificativa de Escolha

Arduino Uno / Nano (ATmega328P)

Microcontrolador

Funcionamento Técnico:

Microcontrolador RISC de 8 bits operando a 16 MHz. Gerencia entradas/saídas por registradores internos de I/O e possui periferia TWI para barramento I²C.

Justificativa da Escolha:

Baixo custo, excelente estabilidade para temporizações de leitura e compatibilidade universal com bibliotecas de instrumentação.

Sensor DHT11 / DHT22

Sensor Termo-Higrométrico

Funcionamento Técnico:

Integra um termistor NTC para temperatura e um sensor capacitivo de umidade. Converte medições internas em um sinal digital digital pré-calibrado.

Justificativa da Escolha:

Evita a necessidade de pontes de medição externas ou conversores A/D dedicados, enviando pacotes imunes a ruídos por pino único.

Módulo RTC DS3231

Real Time Clock

Funcionamento Técnico:

Relógio de tempo real munido de cristal interno TCXO compensado por temperatura. Mantém contagem de tempo via bateria CR2032.

Justificativa da Escolha:

Garante carimbo do tempo das leituras mesmo na ausência de sinal de internet (NTP) e durante reinicializações do sistema.

Display OLED 0.96" SSD1306

Interface Gráfica

Funcionamento Técnico:

Matriz de 128x64 pixels com tecnologia emissiva orgânica (dispensa backlight). Comunicação via endereço I²C 0x3C.

Justificativa da Escolha:

Altíssimo contraste visual, ângulo de visão amplo e consumo elétrico irrisório comparado a telas LCD tradicionais.

07. Firmware Embarcado

Código-Fonte C++ (Arduino)

estufa_monitor.ino Placa: Arduino Uno / Nano (ATmega328P) 
/*
 * PROJETO: Sistema de Monitoramento Termo-Higrométrico para Estufas
 * CURSO: Engenharia Elétrica
 * COMPONENTES: Arduino, Sensor DHT, RTC DS3231, Display OLED SSD1306, LEDs
 */

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <RTClib.h>
#include <DHT.h>

// Configuração do Display OLED (128x64 I2C)
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

// Configuração do Sensor DHT
#define DHTPIN 2
#define DHTTYPE DHT11 // Alterar para DHT22 se aplicável
DHT dht(DHTPIN, DHTTYPE);

// Configuração do RTC DS3231
RTC_DS3231 rtc;

// Pinos dos LEDs Indicadores
#define LED_VERDE 8
#define LED_AMARELO 9
#define LED_VERMELHO 10

// Limites Operacionais de Engenharia
const float TEMP_MIN = 18.0;
const float TEMP_MAX = 28.0;
const float HUM_MIN = 50.0;
const float HUM_MAX = 75.0;

void setup() {
  Serial.begin(9600);
  
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_AMARELO, OUTPUT);
  pinMode(LED_VERMELHO, OUTPUT);

  // Inicialização do Sensor DHT e I2C
  dht.begin();
  
  if (!rtc.begin()) {
    Serial.println("Erro ao encontrar modulo RTC!");
  }

  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("Erro na alocação do OLED SSD1306");
    for(;;);
  }

  display.clearDisplay();
  display.setTextColor(WHITE);
  display.setTextSize(1);
  display.setCursor(10, 25);
  display.print("ESTUFA TECH V1.0");
  display.display();
  delay(2000);
}

void loop() {
  DateTime now = rtc.now();
  float temp = dht.readTemperature();
  float hum = dht.readHumidity();

  if (isnan(temp) || isnan(hum)) {
    Serial.println("Falha de leitura do sensor DHT!");
    return;
  }

  // Avaliação do Estado do Microclima
  bool tempIdeal = (temp >= TEMP_MIN && temp <= TEMP_MAX);
  bool humIdeal = (hum >= HUM_MIN && hum <= HUM_MAX);

  digitalWrite(LED_VERDE, LOW);
  digitalWrite(LED_AMARELO, LOW);
  digitalWrite(LED_VERMELHO, LOW);

  if (tempIdeal && humIdeal) {
    digitalWrite(LED_VERDE, HIGH); // Condição Perfeita
  } else if (!tempIdeal && !humIdeal) {
    digitalWrite(LED_VERMELHO, HIGH); // Ambas fora de faixa
  } else {
    digitalWrite(LED_AMARELO, HIGH); // Alerta parcial
  }

  // Renderização no Display OLED
  display.clearDisplay();
  
  // Cabeçalho Horário
  display.setCursor(0, 0);
  display.print("HORA: ");
  if(now.hour() < 10) display.print('0');
  display.print(now.hour()); display.print(':');
  if(now.minute() < 10) display.print('0');
  display.print(now.minute());

  display.drawLine(0, 10, 128, 10, WHITE);

  // Exibição de Telemetria
  display.setCursor(0, 20);
  display.print("Temp: "); display.print(temp, 1); display.print(" C");
  
  display.setCursor(0, 36);
  display.print("Umid: "); display.print(hum, 1); display.print(" %");

  // Barra de Status Inferior
  display.drawLine(0, 52, 128, 52, WHITE);
  display.setCursor(0, 55);
  if (tempIdeal && humIdeal) display.print("STATUS: IDEAL");
  else display.print("STATUS: ALERTA!");

  display.display();
  delay(2000); // Intervalo de amostragem
}
