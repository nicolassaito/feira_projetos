Sistema de Monitoramento de Temperatura, Umidade e Gases

Monitoramento ambiental com Arduino, sensor DHT11 para temperatura e umidade, sensor de gás e fumaça, display OLED e sinalização visual por LEDs.

Testar Simulador Interativo Ler Especificações

01. Fundamentação

Proposta Técnica do Projeto

Desenvolvido como projeto integrador no curso de Engenharia Elétrica, focado em instrumentação eletrônica, protocolos de comunicação e controle visual.

Monitoramento de Temperatura

A temperatura é medida continuamente pelo DHT11. Como referência inicial, acima de 30°C o sistema aciona o LED vermelho e apresenta um alerta no display. Esse limite pode ser alterado no código.

Umidade Relativa do Ar (%RH)

O DHT11 também mede a umidade relativa do ambiente, permitindo acompanhar as condições do ar em tempo real.

Detecção de Gás e Fumaça

A leitura do sensor é acompanhada continuamente. Quando o valor ultrapassa o limite de referência configurado, o sistema ativa o alerta visual.

Objetivos de Engenharia

DHT11 Temperatura e umidade
MQ Detecção de gás e fumaça
2 LEDs Estado normal e alerta
OLED Exibição das medições

02. Topologia do Sistema

Funcionamento do Circuito & Classificação

CONTROLADOR

Microcontrolador ATmega328P

Processa os dados seriais do sensor DHT, requisita informações de hora via barramento I²C e gerencia as saídas lógicas.

SENSOR

Sensor DHT11

Realiza a leitura da temperatura e da umidade relativa do ar e envia os valores ao Arduino por comunicação digital.

SENSOR

Sensor de Gás e Fumaça

Detecta a presença de gases e fumaça no ambiente. O Arduino interpreta a leitura analógica do módulo e compara o valor com um limite configurado.

ATUADOR / EXIBIÇÃO

Display OLED 0.96" SSD1306

Interface visual que apresenta temperatura, umidade, nível de gás/fumaça e estado atual do ambiente em uma matriz de 128x64 pixels.

ATUADOR SINALIZADOR

LEDs Indicadores de Estado

Dois LEDs indicam a condição do ambiente: verde para operação normal e vermelho quando a temperatura ou a leitura de gás/fumaça ultrapassa o limite configurado.

Fluxograma de Lógica de Controle

Clique em qualquer etapa para destacar o comportamento do sistema:

1
POWER-ON & INICIALIZAÇÃO Inicializa o display OLED, o DHT11, o sensor de gás e os pinos dos LEDs
2
AQUISIÇÃO DE DADOS Obtém temperatura e umidade pelo DHT11 e leitura analógica do sensor de gás
3
COMPARAÇÃO DE LIMITES Verifica se a temperatura ultrapassou 30°C ou se a leitura de gás/fumaça passou de 400 (valor de referência ajustável)
4
SINALIZAÇÃO E DISPLAY Exibe as três medições no OLED; verde indica normalidade e vermelho indica alerta
5
INTERVALO DE LEITURA (2000ms) Aguarda o próximo ciclo de aquisição dos sensores

04. Especificação de Hardware

Componentes Técnicos e Justificativa de Escolha

Arduino Uno / Nano (ATmega328P)

Microcontrolador

Funcionamento Técnico:

Microcontrolador RISC de 8 bits operando a 16 MHz. Gerencia entradas/saídas por registradores internos de I/O e possui periferia TWI para barramento I²C.

Justificativa da Escolha:

Baixo custo, excelente estabilidade para temporizações de leitura e compatibilidade universal com bibliotecas de instrumentação.

Sensor DHT11

Sensor Termo-Higrométrico

Funcionamento Técnico:

Integra um sensor de temperatura e um sensor capacitivo de umidade. Envia os valores medidos ao Arduino por sinal digital.

Justificativa da Escolha:

Simplifica a aquisição de temperatura e umidade, utilizando apenas um pino digital do Arduino.

Sensor de Gás e Fumaça

Sensor ambiental

Funcionamento Técnico:

O módulo fornece uma leitura proporcional à resposta do elemento sensor. Na ligação analógica, o Arduino lê o sinal pela entrada A0, com valores de 0 a 1023.

Justificativa da Escolha:

Permite identificar aumento na presença de gases e fumaça e integrar um alerta ao sistema. O limite 400 é apenas uma referência inicial e deve ser ajustado após testes. A leitura bruta não representa ppm sem calibração específica.

Display OLED 0.96" SSD1306

Interface Gráfica

Funcionamento Técnico:

Matriz de 128x64 pixels com tecnologia emissiva orgânica (dispensa backlight). Comunicação via endereço I²C 0x3C.

Justificativa da Escolha:

Altíssimo contraste visual, ângulo de visão amplo e consumo elétrico irrisório comparado a telas LCD tradicionais.

06. Firmware Embarcado

Código-Fonte C++ (Arduino)

monitor_ambiental.ino Placa: Arduino Uno / Nano (ATmega328P) 
/*
 * PROJETO: Sistema de Monitoramento de Temperatura, Umidade e Gás/Fumaça
 * PLATAFORMA: Arduino Uno
 * SENSORES: DHT11 e módulo de gás/fumaça com saída analógica
 * SAÍDAS: Display OLED SSD1306, LED verde e LED vermelho
 */

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <DHT.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

#define GAS_PIN A0
#define LED_VERDE 8
#define LED_VERMELHO 9

// Ajuste os limites conforme os testes e a calibração do protótipo.
const float LIMITE_TEMPERATURA = 30.0;
const int LIMITE_GAS = 400;

void setup() {
  Serial.begin(9600);

  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_VERMELHO, OUTPUT);

  dht.begin();

  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("Falha ao iniciar o display OLED.");
    while (true) {
    }
  }

  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(10, 25);
  display.println("MONITOR AMBIENTAL");
  display.display();
  delay(2000);
}

void loop() {
  float temperatura = dht.readTemperature();
  float umidade = dht.readHumidity();
  int nivelGas = analogRead(GAS_PIN);

  if (isnan(temperatura) || isnan(umidade)) {
    Serial.println("Falha na leitura do DHT11.");
    digitalWrite(LED_VERDE, LOW);
    digitalWrite(LED_VERMELHO, HIGH);
    return;
  }

  bool alertaTemperatura = temperatura > LIMITE_TEMPERATURA;
  bool alertaGas = nivelGas > LIMITE_GAS;
  bool estadoAlerta = alertaTemperatura || alertaGas;

  digitalWrite(LED_VERDE, estadoAlerta ? LOW : HIGH);
  digitalWrite(LED_VERMELHO, estadoAlerta ? HIGH : LOW);

  display.clearDisplay();
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("MONITOR AMBIENTAL");
  display.drawLine(0, 10, 128, 10, SSD1306_WHITE);

  display.setCursor(0, 17);
  display.print("Temp: ");
  display.print(temperatura, 1);
  display.println(" C");

  display.setCursor(0, 30);
  display.print("Umidade: ");
  display.print(umidade, 0);
  display.println(" %");

  display.setCursor(0, 43);
  display.print("Gas/Fumaca: ");
  display.print(nivelGas);
  display.println("/1023");

  display.drawLine(0, 55, 128, 55, SSD1306_WHITE);
  display.setCursor(0, 57);
  display.print(estadoAlerta ? "STATUS: ALERTA" : "STATUS: NORMAL");

  display.display();

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.print(" C | Umidade: ");
  Serial.print(umidade);
  Serial.print(" % | Gas/Fumaca: ");
  Serial.println(nivelGas);

  delay(2000);
}
